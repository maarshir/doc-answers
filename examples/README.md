# Пример документов

Это вымышленная памятка сотрудника вымышленной веб-студии «Клён». Все правила, цифры и названия придуманы для примера и не относятся к реальной компании. Тексты написаны специально для этого репозитория, чужих текстов здесь нет.

На папке `docs` работают примеры из README, тесты и набор вопросов в `eval/questions.yaml`.

В `hard/docs` документы той же студии для трудного набора вопросов `eval/hard.yaml`.
